# 流域协同评估

流域治理项目的污染削减与温室气体减排协同评估后端。每个治理措施登记适用河段、
污染物、能源活动、基准期间与证据来源；指标结果依赖基准版本、证据来源与措施间关系。

## 核心机制

- **登记**：`Measure` 登记卡记录河段、污染物、能源活动、实施窗口、基准期间、
  证据来源与先后依赖；证据沿用 `contracts.MeasureEvidence`（关联基准版本、指标、数值与单位）。
- **规则版本化**：`RuleSet` 不可变且钉住基准版本；规则修订只发布新版本，不覆盖旧版本，
  新旧口径并排可比。
- **快照**：评估前冻结全部登记数据为 `Snapshot`；补齐监测、许可调整改变基准等修正
  以追加记录的方式进入下一份快照，历史快照不变。
- **重复计入识别**：同一证据被多个措施引用时生成 `duplicate_evidence` 冲突并给出
  风险金额；合计按证据去重，同时保留未去重的 `gross_totals` 展示重复计入规模。
- **先后依赖**：拓扑排序决定计算顺序；未知依赖、先后倒置、依赖成环的措施被阻塞
  （`blocked`）并记入冲突。
- **监测缺期**：实施窗口内缺监测月份的指标按规则策略挂起（`pending_data`）或标记估算
  （`estimated`）。
- **评审**：按指标粒度退回/确认，决定与报告分离存放——退回只改变生效集合，
  不丢弃其他有效结论，被退回指标进入"退回待整改"。
- **差异归因**：任意两份报告（不同统计边界、不同口径、不同数据）逐项对比，
  依据指标溯源信息解释差异来源（边界权重、排放因子、基准版本、状态、证据集合）。
- **原口径复算**：引擎是纯函数，`replay` 用冻结快照 + 原规则版本 + 原边界重算，
  验证历史报告未被数据或规则变化影响。

## 模块

| 模块 | 职责 |
| --- | --- |
| `contracts.py` | 评估窗口与措施证据契约（原始骨架，保持兼容） |
| `domain.py` | 河段、措施登记卡、证据来源、监测记录、基准版本、统计边界 |
| `rules.py` | 不可变规则版本（基准版本、排放因子、缺期与去重策略） |
| `snapshot.py` | 数据快照冻结 |
| `dependencies.py` | 措施依赖的拓扑排序与结构校验 |
| `evaluation.py` | 评估引擎与不可变报告 |
| `review.py` | 指标级评审 |
| `reconcile.py` | 报告间差异归因 |
| `portfolio.py` | 组合视图：协同收益、冲突项、待核实数据 |
| `service.py` | 服务接口门面（登记/评估/评审/对账/复算） |

## 运行

```bash
python3 -m unittest discover -s tests -v   # 测试
python3 -m compileall -q src tests         # 编译检查
python3 examples/annual_review_demo.py     # 年度复盘演示
```

演示脚本走一遍完整流程：年末评估 → 评审退回重复计入指标 → 流域/行政边界对账 →
补齐监测与许可调整改变基准 → 新口径生成可比版本 → 历史报告按原口径复算验证。
